# Terminal Video Player v0.1.1

This public prerelease provides the first automated Windows x64 portable
package. It remains an unsigned proof of concept.

The package contains Terminal Video Player plus independently source-built
FFmpeg 9.0.1 `ffmpeg.exe` and `ffprobe.exe`. FFmpeg is a separate third-party
program under LGPL 2.1 or later for the audited minimal configuration. The
release also includes checksums, an SPDX 2.3 SBOM, a deterministic package
manifest, provenance, a two-run reproducibility report, and an exact
corresponding-source bundle.
Detected license and notice files for every package in the locked Rust release
graph are included under `licenses/Rust` with a hashed inventory.

Verify the portable ZIP against its adjacent `.sha256` asset before running it.
Extract the complete archive so the player can resolve the bundled tools from
`tools\ffmpeg` when no explicit FFmpeg directory override is configured.

Known limitations include unsigned executables, Windows x64 only, proof-of-
concept status, incomplete long-duration A/V synchronization evidence, and the
minimal FFmpeg format/component allowlist documented in the README.
